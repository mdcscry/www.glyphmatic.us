# Codex Project Instructions

## Default Tooling
- Always use Serena for code navigation/edit workflows when available.
- Treat `.serena/project.yml` as the project-specific Serena source of truth.
- Treat `~/.serena/serena_config.yml` as Serena global defaults.
- Always respect `.roborev.toml` for review-agent behavior and review guidelines.

## Startup Checklist (Every Session)
1. Confirm this repository is trusted and active.
2. Read `AGENTS.md`, `.serena/project.yml`, and `.roborev.toml`.
3. For palette work, follow `tools/paintings/PALETTE_SKILL.md` and prefer `bin/palette_one.sh`.
4. Follow Roborev review constraints and Serena project context before making edits.

## Notes
- This project is browser-first creative coding with no build step unless explicitly requested.
- Do not remove or rename `.roborev.toml` or `.serena/` contents unless explicitly requested.
