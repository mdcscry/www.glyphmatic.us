# European Language Diacritics Reference

This document lists European languages and their distinctive characters, extracted from a popular language identification flowchart. This can be used for QA testing of the flagsfun implementation.

**Note:** This reference is based on a community-created flowchart and may contain inaccuracies. Use for general reference and testing purposes.

## Baltic Languages

### Latvian (latviešu)
- **Distinctive characters**: ē, ū, č, š, ā, ģ, ķ, ļ, ņ
- **ISO Code**: LV

### Lithuanian (lietuvių)
- **Distinctive characters**: ė, ų, č, š, ū, į, ą
- **ISO Code**: LT

- Some minority languages may be missing
- Character lists may not be exhaustive for all languages
