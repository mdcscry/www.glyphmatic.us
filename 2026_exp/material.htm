info URL Parameters

URL Parameters

?tester=true - Show selection panel for building hex arrays

?glyph_picker=true - Show selection panel with comma-separated output

?mode=blacklist - Show ONLY blacklisted glyphs for testing

?fixed=true - Use fixed font settings instead of random variations

?hex=E000 - Show specific hex codepoint(s)
Supports comma-separated: ?hex=E000,E88E,F000 (all mixed randomly)

?icon_name=home - Render by icon name
Supports comma-separated: ?icon_name=home,info,settings (all mixed randomly)

?variant=outlined|rounded|sharp|legacy - Choose font variant (default: random)

Examples:

material.htm?tester=true

material.htm?glyph_picker=true

material.htm?mode=blacklist&tester=true

material.htm?hex=E88E&variant=sharp

material.htm?hex=E000,E88E,F000&fixed=true

material.htm?icon_name=home,info,star

material.htm?variant=rounded&fixed=true
