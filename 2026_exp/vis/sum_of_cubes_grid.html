1³ + 2³ + 3³ + ··· + n³ = (1 + 2 + 3 + ··· + n)²

Each panel: n nested gnomons of k×k squares tile a triangular-number-sized square. 50 random variations.

Each k×k square in the kth gnomon contributes area k². There are k of them, so the kth gnomon has area k·k² = k³. Stacked together, n gnomons fill a square of side T(n) = 1+2+···+n, area T(n)². So Σk³ = T(n)².
