Extended-A Page Tester

Instructions

Goal: Find where each PDF page's glyphs are mapped in Aegyptus's PUA block.

Method: For each page, adjust the PUA start point until the last highlighted glyph matches the last glyph shown in your PDF.

The last glyph in each grid is highlighted in orange - this should match the last glyph on the corresponding PDF page.

Notes

  • Page 1 starts at F3000 (confirmed)
  • We're off by ~38 glyphs total, so PUA start points won't be simple +100 increments
  • The extra glyphs might be variants, rotations, or Douros's additions
  • When you find the correct PUA start for a page, click "Save This Mapping"
